# 🌍 EcoLife — Environmental Awareness Website

### 🌱 Small Steps, Greener Future!

**EcoLife** is a modern environmental awareness website designed to encourage people to adopt eco-friendly habits and contribute towards a cleaner, healthier, and more sustainable planet.

The website highlights important environmental issues, promotes responsible waste management, and shares simple sustainability tips that people can follow in their daily lives.

---

## ✨ Features

* 🌿 **Clean & Modern UI** — A visually appealing design with a green environmental theme.
* 🌎 **Environmental Awareness** — Highlights major environmental challenges affecting our planet.
* ♻️ **Waste Management** — Encourages responsible waste disposal and recycling.
* 🌱 **Sustainable Living** — Promotes eco-friendly habits for everyday life.
* 💡 **Eco-Friendly Tips** — Provides simple ideas to help users live more sustainably.
* 📩 **Contact Section** — Includes a contact form design for user interaction.
* 📱 **Responsive Design** — Designed with a focus on usability across different screen sizes.

## 🚀 How to Run the Project

Want to explore the website on your computer? Follow these steps:

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the downloaded project folder.

3. Locate the `index.html` file.

4. Open `index.html` in your web browser.

🎉 That's it! Your EcoLife website is ready to explore.
